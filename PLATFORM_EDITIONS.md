## Subscription Lifecycle

```
trial_started → trialing → activated → active
                                         │
                              ┌──────────┼──────────┐
                              ▼          ▼          ▼
                         past_due    upgraded    downgraded
                              │
                              ▼
                         suspended ──→ reactivated ──→ active
                              │
                              ▼
                         cancelled ──→ expired
```

### Status Definitions

| Status | Description |
|---|---|
| `trialing` | Free trial period active |
| `active` | Paid and in good standing |
| `past_due` | Payment failed, grace period |
| `suspended` | Access restricted due to non-payment |
| `cancelled` | Cancellation requested, access until period end |
| `expired` | Subscription ended, no access |

### Event Types

| Event | Trigger |
|---|---|
| `created` | New subscription provisioned |
| `trial_started` | Trial period begins |
| `trial_ended` | Trial period expires |
| `activated` | First successful payment |
| `upgraded` | Moved to higher edition |
| `downgraded` | Moved to lower edition |
| `renewed` | Billing period renewed |
| `payment_failed` | Payment attempt unsuccessful |
| `payment_recovered` | Overdue payment collected |
| `suspended` | Access restricted |
| `cancelled` | User-initiated cancellation |
| `reactivated` | Resumed after suspension/cancellation |
| `expired` | End of subscription term |
